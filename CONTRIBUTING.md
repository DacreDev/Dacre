# Contributing

Dacre is an early, independently maintained fork. Bug fixes are the most useful contribution.

Open an issue before you build a new feature, so we can agree that it fits.

## Rules for a pull request

<a id="one-problem"></a>

### One problem per pull request

Fix one problem. Include every change that fix needs across contracts, server, clients, tests, and
docs. Cleanup, refactors, and a second fix go in their own pull requests.

<a id="verification"></a>

### Show that it works

Say how you found the bug (or what your feature changes), how you checked it, and what you saw.
"Tests pass" is not evidence.

UI changes need before and after screenshots. Add a short video when the change is about motion or
timing. Upload them to the pull request. Do not commit them.

## Security problems

Do not report security problems in public issues. Follow [SECURITY.md](./SECURITY.md).
